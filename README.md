## Installation

Prerequisites:

- Python 3.13 or newer
- uv

Steps:

```bash
# Clone the repository
git clone https://github.com/TripsJ/QRMaker.git

# Move into the project directory
cd QRMaker

# run project
uv run main.py
```

## Usage

Basic example of how to run or use the project:

```bash
uv run main.py
```
 Now just follow the prompts
